About the Project

What is Camundator?

Camundator is a learning and demonstration project built around Camunda Platform 7. It helps learners understand business processes, decision models, workflow automation and orchestration through practical examples.

The project connects process modelling concepts with a working technical environment, making it easier to experiment, test and learn.

  • Practical examples
  • BPMN and DMN
  • Java and Spring Boot
  • Learning by doing

Our Mission

To make process automation easier to understand, explore and apply — from the first BPMN model to a working system.

"Camundator — from understanding processes to automation."
